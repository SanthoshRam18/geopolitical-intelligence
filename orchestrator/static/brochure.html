About the project

Built to find what no single source can.

Three decades of UN votes, bilateral trade records and live news events — run through four independent analytical models simultaneously, then cross-checked for contradictions. This is not a summary tool.

The problem

Every source shows you one lens. We show you four — and where they disagree.

Geopolitical analysis has a structural blind spot. If you look at trade data alone, you see economic dependencies. If you read today's news, you see today. If you query an LLM, you get a confident summary of things it was trained on — no dates, no primary sources, no way to know if it's describing 2019 or 2024.

None of these sources cross-check against each other. A country can be deeply economically intertwined with a bloc while voting against it at the UN every year. A bilateral relationship can look cooperative in the trade numbers while today's GDELT stream is showing its worst day in a decade. That gap — between what different data sources say about the same country — is the most valuable signal in geopolitical analysis. It's also the one that falls through the cracks of every existing tool.

"A divergence between trade structure and UN voting behaviour isn't noise — it's a structural tension that tells you which way a country might break under pressure."

This system was built to surface those divergences automatically, every time, for any country.

The idea

Four independent agents. One question. Where do they disagree?

The four agents — Soft Power, Policy Stance, Trade Intelligence and Event Summarization — each run entirely separate models on entirely separate datasets. They share only the question asked and the country name. Everything else — the data, the method, the output format — is independent.

The fusion engine then asks: what can we learn from the fact that these four independent systems are looking at the same country and coming to different conclusions? It runs five cross-agent rules, each testing a specific hypothesis that requires data from at least two agents.

The result is findings that no individual agent — and no summary-based tool — could produce:

What makes it different

This is not a language model. Every number has a source.

ChatGPT summarises text. It has a training cutoff, no access to live data, and no way to tell you which year it's describing. Ask it about India–China trade and it will give you a paragraph — without citing which BACI release, which year, which HS2 sector categories, or what the confidence interval is on that claim.

Every output from this system is traceable. Each finding cites which agent produced it, which dataset it came from, which year the data covers, and what the confidence score was. The briefing shows the exact pipeline: plan → agent responses → fusion findings → narrative. You can see the working.

An LLM can tell you "India and China have complex trade relations." This system tells you: China carries 14.2% of India's total trade (BACI 2023), India sits in the Non-Aligned UN bloc while China sits in the Eastern Bloc, and today's GDELT Goldstein score for the pair is −2.3 against a 30-year GGE baseline of +0.4.

The four agents

What each one does and how

Soft Power Agent
Soft Power Index 2000–2024 · 5 dimensions · 185 countries
  • Composite score time series with Kalman filter smoothing — removes noise, preserves trend
  • SHAP attribution: which of the 5 dimensions (culture, diplomacy, education, digital, economy) drove a year's change and by how much
  • Kalman forecast with confidence envelopes — not just a point estimate
  • K-means peer clustering with silhouette validation to find comparable countries
  • Outputs: influence score, trend direction, SHAP breakdown, forecast range, closest peer countries
Policy Stance Agent
UN GA votes 1989–2025 · UCDP conflict · 185 countries
  • Graph Neural Network: countries embedded in a vote-similarity graph. Stance is a learned embedding, not a hand-coded label
  • Louvain community detection: bloc structure discovered from the vote graph, not from geography
  • Topic-by-topic stance breakdown across 36 years of votes
  • UCDP conflict scoring: active conflict exposure and intensity
  • Outputs: bloc assignment, vote alignment rates, conflict exposure, diplomatic stance vector
Trade Intelligence Agent
BACI bilateral trade 1995–2024 · 226 economies · HS2 sectors
  • Network-based bloc detection: trading blocs identified from flow data, not political categories
  • Critical partner dependence: which single relationship accounts for the most of a country's trade
  • Supply fragility by sector: how concentrated is a country's import sourcing for energy, agriculture, electronics
  • Shock simulation: cascade a supply disruption through the full 226-node trade network
  • Kalman forecasts on export/import trajectories with trend direction signals
Event Summarization Agent
GDELT live stream · GGE historical baseline 1990–2024
  • spaCy NER: entity extraction from raw GDELT event descriptions to attribute events to country pairs correctly
  • K-means theme clustering on CAMEO event codes to identify dominant event types
  • Goldstein scale scoring: quantitative tone for each event and aggregated per bilateral pair
  • GGE baseline deviation: is today's tone statistically out of character for this relationship's 30-year history?
  • Outputs: event count, Goldstein score, dominant themes, bilateral partner activity, baseline deviation flag
Architecture

System design

Five FastAPI microservices, each containerised independently with Docker Compose. Caddy handles HTTPS termination via sslip.io — no domain needed. The orchestrator fans a question out to all four agents in parallel, streams each result as it arrives via NDJSON chunked transfer (no WebSocket, no polling), then runs the fusion engine once all four have responded.

# POST /run → real-time NDJSON stream {"type": "plan", intent, iso3s, agents, time_window, severity} {"type": "agent", agent:"soft_power", result.insights[], result.envelope} ← arrives as it lands {"type": "agent", agent:"policy_stance", result.insights[], result.envelope} {"type": "agent", agent:"trade_intelligence", ...} {"type": "agent", agent:"event_summarization", ...} {"type": "fusion", fused.findings[], fused.stats, briefing, time_alignment} ← cross-agent output

Nine intent types are recognised: country_profile bilateral shock forecast blocs events ranking event_history vote_alignment. The intent parser extracts entities, time windows, severity and sector from free-form English and routes accordingly.

The key innovation

Cross-agent fusion: five rules, two datasets each

Fusion is not averaging. Each rule tests a specific hypothesis that requires data from two different agents — a finding neither agent could produce alone. All five rules run on every query; the results are ranked by confidence × kind weight × intent relevance.

Rule 1 — Bloc alignment

Compares the trading bloc anchor (Trade agent, from BACI flow analysis) against the UN bloc assignment (Policy Stance agent, from vote-graph community detection). If country X trades inside a bloc but votes outside it, this is a divergence — a structural economic-diplomatic tension.

TradePolicy Stance
Rule 2 — Critical partner across the bloc line

Checks whether the country's most critical trade dependency (Trade agent: highest share partner) sits in the same UN bloc as the country itself (Policy Stance agent). A country whose biggest trade partner votes on the other side of the UN is structurally exposed in a way that neither dataset reveals alone.

TradePolicy Stance
Rule 3 — Momentum agreement

Compares the trade trajectory direction (Trade agent: Kalman forecast trend) against the soft power direction (Soft Power agent: SHAP-attributed trend). Two completely independent models, different datasets, measuring different things. If both say "rising" or both say "falling", the corroboration is statistically stronger than either model alone.

TradeSoft Power
Rule 4 — Event friction vs. trade stakes

Takes the Goldstein score of today's GDELT events for a bilateral pair (Events agent) and compares it against that partner's share of total trade (Trade agent). A conflictual day with your largest trade partner is a materially different signal from a conflictual day with a minor partner — but you need both datasets to know the difference.

EventsTrade
Rule 5 — Today vs. 30-year baseline

Compares GDELT daily Goldstein score (Events agent, live stream) against GGE annual baseline 1990–2024 (Events agent, historical dataset). Same agent, two completely independent data sources — an internal cross-check. A cooperative news day in a historically conflictual relationship is as telling as the reverse.

Confidence arithmetic: corroborations combine as 1 − ∏(1 − cᵢ) (independent evidence strengthens the claim, capped at 0.97). Divergences and conjunctions take min(cᵢ) — only as solid as the weakest side. Findings are ranked by confidence × kind weight (divergence: 1.35, corroboration: 1.20, cross-agent: 1.10) × intent-relevance boost.

ML methods

Models used

Kalman filter — Soft Power & Trade agents

State-space smoothing on annual time series. Used for two tasks: noise reduction on historical scores, and forward forecasting with explicit uncertainty bounds. The filter's process noise and observation noise parameters are fit per-country, so a country with volatile historical data gets wider envelopes.

SHAP (SHapley Additive exPlanations) — Soft Power agent

Decomposes each year's soft power score change into contributions from each of the 5 dimensions. Answers "why did India's soft power score rise in 2022?" with specific, quantified attributions per dimension rather than a qualitative answer.

Graph Neural Network — Policy Stance agent

Countries are nodes; vote similarity is the edge weight. The GNN learns embeddings in a vote-similarity space. Policy stance is the resulting position in that space — a data-derived measure, not a manually assigned category. Used to place countries without full vote records by their structural position in the graph.

Louvain community detection — Policy Stance agent

Modularity-maximising community detection on the UN vote similarity graph. Identifies voting blocs entirely from the data. The bloc labels (Eastern Bloc, Western Bloc, Non-Aligned, etc.) emerge from the graph structure, not from political assumptions.

K-means with silhouette validation — Soft Power & Events agents

Used in two contexts: Soft Power agent uses it to cluster countries by composite profile (finding peer groups). Events agent uses it to cluster GDELT CAMEO codes into dominant event themes. Silhouette scoring ensures the number of clusters is chosen by data quality, not by assumption.

spaCy NER — Event Summarization agent

Named entity recognition on GDELT event descriptions to correctly extract country actors and bilateral pairs from raw news-derived event data. Required because GDELT CAMEO actor codes are often incomplete or ambiguous at the sub-national level.

Infrastructure

Deployment

Docker Compose with six services: orchestrator (FastAPI, port 8000), soft power (FastAPI, port 8101), policy stance (FastAPI, port 8102), trade intelligence (FastAPI, port 8103), event summarization (FastAPI, port 8104), and Caddy as the HTTPS reverse proxy. Caddy uses sslip.io for TLS certificate issuance — no domain purchase required.

Each agent service exposes its own REST API and a React/Vite dashboard served by Caddy directly. The orchestrator serves the three HTML pages (home, features, engine) as static files. Streaming uses chunked transfer encoding with Cache-Control: no-cache, no-transform and X-Accel-Buffering: no to prevent proxy buffering.
